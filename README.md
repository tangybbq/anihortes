# The Anihortes keyboard

The MessagEase keyboard is an alternative keyboard for iOS (and others) using a novel slightly
gesture input approach, allowing full keyboard input on what looks roughly like a 10-key input.

Unfortunately, it seem the developer has been inactive, and there hasn't been an update in 6 years
now. It seems that with a recent iOS update, the iPhone version is no longer functional.

This project captures a bit of Claude Code's work in developing a replacement, from my description
of what was desired, the first working keyboard came about in 56 minutes.

With some additional refinements, and about 30 more minutes, this is now a fully-functional
replacement for the keyboard.  Anihortes is named after the order of the keys on the keyboard.

This is not intended to replace MessagEase's implementation, and will be removed if they decide to
continue development. But, I'm offering this so that those who have come to love this keyboard will
be able to continue to use it, even with the official app no longer working.
